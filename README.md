# JackLoad releases

Android release files for JackLoad, a LamaLo field tool for paired load and dial-indicator readings. This repository holds release downloads only; it contains no source code.

Each release has:
- `JackLoad-<version>-debug.apk`: the app.
- `jackload-update.txt`: the version, file name and SHA-256 that the app's **Help > App updates** reads.
- `JackLoad-User-Manual.pdf`: the user manual.

The app checks this address only when the user taps **Check for updates**:
`https://github.com/zschramm/jackload-releases/releases/latest/download/jackload-update.txt`

Install a downloaded APK as an **Update**; do not uninstall first, or saved work on the phone is lost.
